# Security Policy

## Supported Versions

Security fixes are applied to the latest state of the `main` branch.

## Reporting a Vulnerability

Please do not post security-sensitive issues publicly.

If you discover a vulnerability, prepare:

- a short description of the issue
- impact and affected area
- reproduction steps or proof of concept
- suggested mitigation if available

Then report it privately to the repository owner through GitHub or another private contact channel.

## Scope Notes

This project may involve API keys and model provider configuration. Never include real keys, secrets, or private account data in issues, pull requests, screenshots, or logs.
