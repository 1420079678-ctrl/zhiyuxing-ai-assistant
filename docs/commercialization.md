## 2. 核心商业落地场景

### 2.1 企业员工援助计划 (Enterprise EAP & Copilot)
- **痛点**：现代企业员工在高强度交付、频繁加班及组织变动中，普遍面临职业倦怠、无意义感与注意力耗竭。传统外部 EAP 咨询成本高昂、员工顾虑隐私不敢主动预约。
- **方案**：知愈星 AI 可作为企业内部的 24/7 私密心理与效能 Copilot：
  - **精力回血机制**：引导工位 5 分钟微休息与呼吸放松，帮助副交感神经复原。
  - **行动破冰教练**：针对复杂方案或卡壳交付，采用“瑞士奶酪法”拆解最小可行任务。
  - **心理离线边界**：引导建立下班后的关机仪式与心理边界，阻断职场持续内耗。

### 2.2 高校学工与心理健康中心 (Higher-Ed Academic Health)
- **痛点**：高校辅导员与心理教师师生配比严重不足，考试周与毕业季咨询需求集中爆发，高风险个案容易被漏报。
- **方案**：
  - **轻量前置干预**：解决 80% 的学业拖延、复习焦虑与迷茫诉求，释放专业咨询师精力。
  - **合规级三级风险预警**：内置高敏感度安全规则引擎，触发危机表达立即阻断模型并引导线下资源，杜绝次生安全风险。

### 2.3 商业 SaaS 与第三方平台集成
- **钉钉 / 飞书 / 企业微信 协同底座**：已预留标准 Webhook 与 Bot 交互接口，支持无缝嵌入协同办公套件。
- **多租户与 API 鉴权**：支持基于 `X-API-Key` 或 Bearer Token 的租户隔离与流量管控。

## 5. 安全合规与 SLA 保障

1. **数据隐私保护**：
   - 专有化部署模式下，对话与知识数据全部驻留在企业私有 VPC 或本地服务器内，不外流、不回传、不参与外部基础模型预训练。
2. **严守非医疗边界**：
   - 系统严禁输出精神科临床诊断结论，严禁开具处方建议。遇到中高风险表达强制阻断并切换为固定安全转介引导。
3. **企业级可观测性**：
   - 通过标准 Prometheus `/metrics` 端点，实时输出 QPS、P99 延迟、风险拦截计数与 Token 消耗，满足企业 IT 审计需求。
