# src 目录说明

当前仓库是 **展示版（showcase repo）**，暂未包含完整业务源码。

如果你后续要把这个仓库升级成“可运行版”，建议从下面这个结构开始：

```text
src/
├── app.py                # 最小可运行入口
├── prompts/              # Prompt 模板
├── services/             # LLM 调用、心理引导、学习建议等服务
├── routers/              # 接口路由
├── schemas/              # 请求/响应结构
└── utils/                # 工具函数
```

## 最低可运行建议
你至少可以先补一个最简单的 demo：
- 用户输入一句话
- 调用大模型 API
- 返回心理支持/学习建议回复

这样 GitHub 仓库就会从“作品展示”升级为“有演示能力的项目仓库”。
