Run & Integrate

运行与接入说明

项目默认提供浏览器可直接访问的 Web 服务，也保留了钉钉平台集成的扩展空间。

  • 未配置模型密钥时，系统会自动切换到本地演示模式，保证页面和接口可直接运行。
  • 现在支持一键写入 OpenAI、DeepSeek Chat、DeepSeek R1 的模型配置，但真实调用仍需填写对应 API Key。
  • 如果后续接入钉钉，需根据应用类型和授权模型处理组织级权限问题。
