# Roadmap

## Near Term

- improve crisis-expression detection and safer escalation guidance
- refine provider compatibility checks for more OpenAI-compatible services
- improve demo response diversity and conversation continuity
- make web onboarding clearer for first-time users

## Mid Term

- add conversation history and lightweight state management
- support retrieval or curated knowledge sources for study and support guidance
- provide a deployable online demo path
- improve frontend polish, mobile usability, and accessibility

## Long Term

- strengthen DingTalk integration as an optional deployment scenario
- support richer multi-provider switching and runtime observability
- build better safety review and human handoff mechanisms
